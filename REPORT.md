# Какой путь проходит пароль базы от страницы настроек GitHub до переменной окружения в поде? Почему его нельзя положить в configmap.yaml?

Создаем в настройках гитхаба, подтягиваем в качестве переменной окружения в шаге "подтягиваем секреты", дальше прокидываем это на кластер создавая две переменные - ссылку содержашую пароль и только пароль отдельно. Образ потсгрю берет только пароль, образ сервиса берет ссылку целиком

# Уберите мысленно needs: tests у job build. Опишите сценарий, в котором это закончится плохо.

Образ может собраться, но тесты пройдены не были. Билд не предполгает прохождение тестов. 

Например разаработчик поменял случайно выход модели или результат эндпоинта. Если тестов нет, то соберется образ, который раскатится в продакшн. Пользователи сервиса могут столкнуться с ошибками.
